Key design decisions

  • Sections are collapsible — expand only what you care about
  • Each row shows bookmark name + URL + status code
  • Scrollable per section — handles 300+ dead links fine
  • Dead selected by default, Moved + Unreachable unselected
  • Zap button counts total across all categories
  • Confirmation dialog before deletion
  • Toolbar icon opens/closes the sidebar
